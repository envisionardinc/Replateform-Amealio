# Amealio Replatforming Documentation

This directory holds discovery, architecture, and migration documentation for the Amealio replatforming initiative.

**Phase status:** Discovery and architecture. No application implementation yet.

## Structure

| Directory | Purpose |
|-----------|---------|
| [`discovery/`](./discovery/) | Inventory of reference systems, scope, unknowns, and investigation notes |
| [`architecture/`](./architecture/) | Target architecture proposals (pending explicit decisions) |
| [`domain/`](./domain/) | Domain model and bounded-context analysis |
| [`database/`](./database/) | Data model discovery and target database design notes |
| [`migration/`](./migration/) | Data and feature migration strategy |
| [`integrations/`](./integrations/) | External systems (payments, SMS, ONDC, maps, etc.) |
| [`testing/`](./testing/) | Test strategy and parity validation approach |
| [`decisions/`](./decisions/) | Architecture Decision Records (ADRs) requiring or recording approval |

## Starting point

Read [`discovery/REPLATFORMING_SCOPE.md`](./discovery/REPLATFORMING_SCOPE.md) first.
